# Bangla AI Writer — Production Ready Starter

Node/Express + SQLite web app with authentication, quotas, Meta Model API integration, manual bKash/Nagad payment submission, and admin approval.

## Local
npm install
cp .env.example .env
npm start

Open http://localhost:3000

## Production
See `DEPLOY-RENDER-BN.md` and `render.yaml`.

Keep all secrets in environment variables. Never commit `.env`.
